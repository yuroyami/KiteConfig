KiteConfig

One block. Every platform.

App name, id, version, icons and build config for Kotlin Multiplatform apps.

build.gradle.kts
kiteConfig {
    appName = "Jetzy"
    appId   = "com.example.jetzy"
    version = "1.4.0"
    autoApply = true
    logo { foreground = file("jet.png") }
}
