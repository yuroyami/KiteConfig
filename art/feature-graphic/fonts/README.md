# Fonts

The feature graphic uses two fonts, both under the SIL Open Font License 1.1.
The files are the latin subsets that Google Fonts serves, so the page renders the same on every machine.

| File | Font | License |
| --- | --- | --- |
| `plus-jakarta-sans-latin.woff2` | [Plus Jakarta Sans](https://github.com/tokotype/PlusJakartaSans), variable weight 200 to 800 | `OFL-PlusJakartaSans.txt` |
| `fira-code-latin.woff2` | [Fira Code](https://github.com/tonsky/FiraCode), variable weight 300 to 700 | `OFL-FiraCode.txt` |
